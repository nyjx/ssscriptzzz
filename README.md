## 维基百科中文统一跳转脚本
优化维基百科的中文体验。

### 功能
1. **方言跳转**: 自动将粤语、吴语、闽南语等方言页面重定向到中文主站对应条目。
2. **移动端跳转**: 自动将 `m.wikipedia.org` 跳转到桌面版。
3. **繁简统一**: 将所有地区词变体（如 `zh-tw`, `zh-hk`）统一重定向到 `zh-cn`。

[👉 **点击这里安装脚本**](https://raw.githubusercontent.com/nyjx/ssscriptzzz/main/wiki_zh_redirect.user.js)
